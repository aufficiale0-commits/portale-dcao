PORTALE DCAO — PROTOTIPO

Portale didattico per docenti di Difesa contro le Arti Oscure.

CONTENUTI
- Dashboard e programmi dal primo al quinto anno
- Archivio di 16 lezioni per i primi quattro anni
- Enciclopedia DCAO e materiali didattici
- Ricerca interna
- Schede lezione con spiegazioni, precauzioni e note per il docente

COME APRIRE
Aprire index.html in un browser moderno.

PUBBLICAZIONE
Il progetto è un sito statico HTML/CSS/JavaScript. Può essere pubblicato con GitHub Pages dalla cartella root del branch main.

LIMITI DEL PROTOTIPO
Non include autenticazione, database, ruoli utente o salvataggio delle modifiche. Non inserire dati personali o materiali riservati.

NOTA DIDATTICA
Le voci Coloshoo e Verdimillus sono indicate come da verificare/completare, poiché la loro descrizione non era stata definita nel materiale iniziale.
